# 02. 데이터 정리와 개인정보

## 1단계: 이미 모은 사진 정리하기
사진은 이미 모여 있으므로, 먼저 **목록(인벤토리)**을 만든다. 사진을 옮기거나 지우지 말고 복사본으로 작업한다.

1. 사람마다 번호를 붙인다: `S01`, `S02`, … (실명 대응표는 팀 내부에만 따로 보관하고 이 프로젝트에 올리지 않는다)
2. 같은 사람이 **다른 시점**(다른 날, 또는 같은 날 아침·저녁처럼 시간이 떨어진 때)에 찍은 묶음 = 세션 `D1`, `D2`, …
3. 한 세션 안에서 **연달아** 찍은 장 = 반복 `R1`, `R2`, …
4. 파일 이름을 `S01_D1_R1.jpg`처럼 바꾸고(원본은 따로 보관), `metadata.csv`를 채운다. 양식: `metadata_template.csv`

| 열 | 필수 | 내용 |
|---|---|---|
| file | ✔ | 파일 이름 |
| subject_id | ✔ | S01… |
| session_id | ✔ | D1… (사람마다 1부터) |
| rep | ✔ | 1, 2, … |
| taken_at | 권장 | 촬영 시각 (사진 EXIF에서 가져와도 됨) |
| place, light | 권장 | 장소, 조명(천장등/창문/스탠드 등) |
| device | **필수에 가까움** | 폰 기종. 사람마다 같은 폰이어야 함 — 공공데이터 분석에서 기기가 바뀌면 a\* 수준이 크게 달라졌음(docs/07) |
| note | 선택 | 세안 직후, 운동 후, 화장 여부 등 |

## 이상적인 구성과 최소 구성
- 이상: 10명 이상 × 세션 3개 이상(다른 날) × 세션당 3장
- 최소: 사람당 세션 2개 × 세션당 2장. 이보다 적으면 MDC95 계산이 불안정하다.
- 세션 사이에는 피부 상태가 실제로 변하지 않았다고 볼 수 있어야 한다(같은 루틴, 자극 없음). 세션 사이에 새 제품을 썼다면 note에 적고 분석에서 따로 본다.
- 부족하면 무엇을 더 찍어야 하는지 목록을 만들어 팀원에게 요청한다. 추가 촬영 규칙: 같은 장소·같은 조명·같은 폰, 정면, 무표정, 화장 안 함, 앞머리 넘김, 세안 후 10분 이상 지나서.

## 개인정보 원칙 (이 프로젝트는 claude.ai 프로젝트에서 진행)
- **기본은 숫자만 올린다.** 얼굴 사진은 팀원 컴퓨터에서 `code/measure_redness.py`로 측정하고, 결과 `measurements.csv`만 프로젝트 채팅에 올려 분석한다.
- 사진을 프로젝트에 올려야 하는 경우(예: 볼 영역이 제대로 잡혔는지 같이 보기)는 **당사자 동의를 먼저 받고**, 최소 장수만, 프로젝트 지식이 아니라 해당 채팅에만 올린다. 작업 후 그 채팅을 지운다.
- 파일 이름·CSV·결과 문서에 실명, 전화번호, 학번을 넣지 않는다.
- 공개 GitHub 저장소에 얼굴 사진을 올리지 않는다.
- 발표 자료에 팀원 얼굴을 쓰려면 별도로 동의받는다. 앱 데모는 가상 인물(김서연, AI 생성 이미지)을 쓴다.
- 동의 문구 예시(팀 채팅에 남기기): "낯씨 측정 검증을 위해 내 셀카를 팀 내부 분석에 쓰는 것에 동의합니다. 사진은 내 번호(S0x)로만 표시하고, 수치 결과만 발표에 씁니다. 원하면 언제든 삭제를 요청할 수 있습니다."
